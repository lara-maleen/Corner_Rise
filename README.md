# Corner_Rise
This repository contains the R scripts used for analysis of video data collected during the OER NOAA Cruise 2104 to the Corner Rise Seamounts (CRS) in 2021.
Contents

/raw_data — All files required to run the analysis scripts, including processed density files created for each forest patch.
R scripts for data processing, statistical analyses, and figure generation.
Note: To re-create the water column CTD profile, please contact the author. The .cnv CTD data file is too large to host on GitHub. Or see Zenodo repository below.

Dataset
The full coral and sponge community dataset supporting these analyses is archived in Zenodo and openly accessible: DOI: 10.5281/zenodo.18171047.

Usage
You are free to use, adapt, and share this repository for non-commercial purposes, provided proper credit is given. Please cite the following manuscript when using these data or scripts in your work:
Beckmann, L.M., Eveborn, L., Kenchington, E., & Waller, R.G. (2026). Hotspots Beyond Borders: Quantitative Assessment of Vulnerable Marine Ecosystems on the Corner Rise Seamounts with Implications for Conservation Planning. Frontiers in Marine Science (manuscript under review).
